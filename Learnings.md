### Configuration Pane

1. Date selector
2. Cloud filter (?)
	1. You can modify this to choose a value from 1-100 with MAX Cloud coverage. Some days become unavailable as they have a lot of cloud interference (depends on your filter).
3. Configuration dropdown. You get some presets (?) depending on the kind of research you are doing.
4. Data collection options: panel options (TO explore more here)
5. Sentinel version dropdown: Select between Sentinel-2 L2A or Sentinel-2 L1C
6. Layers Selection: Select between different layer filters to visualize better.
